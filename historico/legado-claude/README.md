# Histórico vindo da conta pessoal do Claude

Cópia dos bancos de dados de dois apps antigos, que ficavam na conta pessoal do Claude do Eduardo. Exportado em 19/11/2026. Nenhum script do painel lê esta pasta. Ela existe para guardar o histórico anterior ao que o painel registra sozinho: marcos desde 10/11/2026 e Etapas desde 16/11/2026.

| Arquivo | De onde veio | Conteúdo |
| --- | --- | --- |
| `historico-cronogramas-snapshots.json` | App "Histórico de Cronogramas", coleção `snapshots` | 6 retratos semanais (13/10 a 16/11/2026) das tarefas com Código Tarefa, Make It e Gadens: id, nome, lista, código, status, término, concluída em |
| `historico-cronogramas.csv` | Botão "Baixar histórico completo" do mesmo app | As mesmas 6 semanas em tabela (3.842 linhas, separador `;`) |
| `registro-desvios-antigo-referencia.json` | App "Registro de Desvios" antigo, coleção `referencia` | Término de todas as Etapas por semana, por incorporadora (campo `t`: id da tarefa → data), de 26/10 a 16/11/2026 |
| `registro-desvios-antigo-marcos.json` | Mesmo app, coleção `marcos` | Datas de Registro de Incorporação (leg010), Lançamento (inc002) e Fim Due Diligence (inc001) por lista e semana, Make It |
| `registro-desvios-antigo-discussao.json` | Mesmo app, coleção `discussao` | Etapas marcadas como discutidas em cada reunião (out/2026) |
| `registro-desvios-antigo-projetistas.json` | Mesmo app, coleção `projetistas` | Lista de projetistas e consultores cadastrados no autocompletar |
